#  Global Car Sales Analysis

##  Project Overview

This project focuses on analyzing global car sales data to identify sales trends, customer preferences, brand performance, and regional patterns.

The project uses Python, SQL, Excel, and Power BI to clean, analyze, visualize, and present the data.

---

##  Project Objectives

- Analyze global car sales performance
- Identify top-performing car brands and models
- Analyze sales by region and country
- Identify sales trends over time
- Explore customer and vehicle characteristics
- Create meaningful KPIs and business insights
- Build interactive dashboards and visualizations

---

##  Tools & Technologies

- SQL
- Excel
- Power BI
- Pandas
- NumPy
- Data Analysis
- Data Visualization
